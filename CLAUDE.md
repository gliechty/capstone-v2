# CLAUDE.md

## Capstone v2

Follow the repository-wide rules in `AGENTS.md`.

Before substantial work, read the canonical control documents listed there.

Important reminders:

- The Build Pack is a baseline, **not a target architecture**.
- Preserve formulas and the config-driven assessment model.
- Do not silently merge canonical config entities.
- Improve implementation, UX, speed, reliability, and architecture where useful.
- Golden Tests are regression guards, not a ceiling.
- Work only inside the currently authorized `BUILD_PLAN.md` milestone.
- Stop for human review on methodology/config-semantic/major dependency changes.
- Obey `COLUMBIA_IP_GUARDRAILS.md`; do not build future commercial differentiation by default.
- Do not claim a milestone is complete; the human project owner advances milestones.

For any significant change, prefer:
1. inspect relevant code/config;
2. state a short plan;
3. implement;
4. test/verify;
5. summarize changes and tradeoffs.

Do not attempt to build the entire product in one pass.
