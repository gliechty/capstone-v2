# M1.1 — UI system and landing-page shell

Implementation for human review; this does not mark M1.1 or Milestone 1 complete.

## Scope and architecture

The owner authorized M1.1 in EXECUTION_PLAN.md after the M1.0 scaffold.
This extends ADR 0001's original scaffold-only authorization without changing its
architecture. The landing page is a server component with semantic HTML and native
disclosures; no client state or new npm dependency is needed. No later execution
step is implemented. The deterministic domain and enforcement remain unchanged.

The shell contains context, approach, a video placeholder, research/provenance and
the exact primary CTA label, "Take the Assessment".
The CTA is a native disabled button with a visible, associated availability message.
It does not navigate to a missing route or create assessment setup ahead of M1.2.
The video placeholder has no pretend player or unavailable media request.

## Visual choices for review

- Warm paper #faf8f3, charcoal #282b29, muted text #5f625c and rust #9d402d.
- One sans-serif: self-hosted variable Manrope, primarily weights 400 and 600.
- Responsive display 40–64px, section headings 32–42px, 17px body, 14px labels.
- 1184px maximum outer container; narrower reading columns; 48–96px section rhythm.
- 10px controls / 14px panels, 1px borders, one very light panel shadow.
- Original inline SVG bridge illustration suggests SMEs meeting buyer expectations.
  It is decorative, not a data visualization or an institutional logo.
- Central tokens cover color, type, spacing, corners, borders, shadow, focus,
  motion and reserved category accents; Tailwind maps to these tokens.
- 220ms entrance fade/6px slide and color transitions. Reduced motion removes
  entrance animation and smooth scrolling and sets transition duration to zero.
- Native keyboard navigation, skip link, visible focus, semantic landmarks,
  native disclosure controls and persistent mobile navigation without a menu dependency.

No generic ESG icon set, gradients, stock logos, dense dashboard cards or remote
font service. Category accents are reserved styling tokens, not scoring configuration.

## Verification and review

The combined verification command includes domain/lint regression checks, landing
unit checks, production build and browser checks. Browser coverage includes desktop
1440px, mobile 390px and narrow 320px, no horizontal overflow, axe on collapsed and
expanded disclosures, keyboard/skip-link behavior, reduced motion, CTA availability,
unknown-route 404 and browser errors. Full-page captures are generated inside
ignored test-results paths for human visual review.

Golden scoring execution is not applicable: no engine or formula changed.
The previously accepted development dependency advisory remains separately
documented in DEPENDENCY_RISKS.md; no dependency versions changed.

Next is owner review of palette, typography, copy and responsive layout.
M1.2 remains unstarted pending explicit authorization.
